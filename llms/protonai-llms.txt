# Proton.ai

> Proton is an AI industry cloud platform built for B2B distributors. Its REST API exposes AI product recommendations (cart, reorder, similar, bought-also-bought, recently-viewed), behavioral tracking, and CRM operations across customers, contacts, opportunities/pipelines, quotes, leads, call notes, tasks, and custom fields. Authentication is a static API key in the X-Api-Key header plus an X-Company tenant header.

## APIs
- [Proton API documentation](https://api.proton.ai/): Public Postman documentation for the AI recommendation + CRM REST API (56 operations).
